# Zouuabi/homebrew-tap

Homebrew casks for my tools.

```bash
brew install --cask zouuabi/tap/cleanmydev
```

| Cask | What |
|---|---|
| `cleanmydev` | [CleanMyDev](https://github.com/Zouuabi/CleanMyDev), a Mac cleaner that understands developers |

The cask version and checksum are bumped automatically by CleanMyDev's release workflow.
